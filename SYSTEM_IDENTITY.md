# PartFlow

This is a standalone desktop edition for automotive spare-parts stores.

- Windows application ID: `com.helperstechnologies.autoparts`
- Local database: `autoparts-inventory.secure.sqlite`
- Local storage namespace: `autoparts_inventory_v1::`
- Product name: `PartFlow`
- Device code: `APW-…`
- License and support codes: `APLIC.…` and `APSUP.…`

It has no shared runtime data, signing key, license code format, or default
online license backend with `helpers-warehouse-system`. The seeded catalogue is
already tailored to automotive parts, including filters, brakes, engine
components, electrical parts, tyres, body parts, cooling and suspension.
