## Upcoming Features (مقترحة - لسه مش موجودة في السيستم)

> دي مش features موجودة فعلاً، ده اقتراح بس لحاجات ممكن تتضاف مستقبلاً.

- تطبيق موبايل (Mobile App) للمالك أو الفروع لمتابعة المبيعات والمخزون من بره
- بوابة أونلاين للعملاء (Customer Portal) لمتابعة كشف حسابهم وطلباتهم
- ربط مباشر مع منصات بيع أونلاين (E-commerce Integration)
- تطبيق للسواقين (Driver App) لتتبع التوصيل لحظة بلحظة
- تنبؤ بالطلب على القطع (Demand Forecasting) باستخدام AI
- ربط مع بوابات دفع إلكتروني (Online Payment Gateway) غير الدفع عند الاستلام
- تكامل مع أنظمة محاسبة خارجية (زي QuickBooks)
- API عام للمطورين والتكاملات الخارجية
